# 楼层书摘 · SillyTavern 扩展 1.1

从楼层更多操作菜单的书本图标打开，摘录选中文字或整层正文，设置后手动生成 PNG。

## 安装 / 更新

将 ZIP 内的 sillytavern-bookmark 文件夹放入 SillyTavern 的 public/scripts/extensions/third-party/。更新时覆盖同名文件夹，刷新页面。目录内部应直接包含 manifest.json、index.js、style.css。

这是本地安装包，未发布到 Git 仓库，不能把 ZIP 地址填到扩展的 Git 安装框。

## 使用

1. 可先选择某层文字，再点击该楼层菜单的「生成书摘」。面板支持切换选中片段 / 整层正文。
2. 确认 user 名称，额外名称每行一条，按字面精确匹配，区分大小写，较长名称优先。
3. 选择毛玻璃马赛克，或者上传 PNG / JPG / WebP 作为遮罩。图片不超过 8 MB，仅在本地读取，会缩放到遮罩尺寸。
4. 选择排版、字号和字体；字体可跟随酒馆、选择宋体或黑体、填写本机已有字体名称，或者上传 WOFF2 / WOFF / TTF / OTF（不超过 25 MB）。字体不存在或缺字时浏览器会回退。
5. 自定义背景色和字体颜色。切换排版会重置这两种颜色为模板默认值，之后可以继续修改。
6. 点击「生成图片」，确认后保存全部 PNG 或逐张保存。修改任意设置会清空旧图，需要重新生成。

## 外观

使用酒馆原生 menu_button、text_pole 和 SmartTheme 颜色变量，继承酒馆字体。面板背景取酒馆主题底色，去掉透明度，强制为 100% 不透明；面板外的遮挡层仍为半透明。截图背景始终不透明。第三方美化若只针对其他面板的专用选择器，本插件不会自动获得那些专属规则。

## 隐私与遮罩

原文编辑框显示真实文字。生成前，将匹配名称移除并替换成固定宽度的绘制占位符，原名不会画入图片，也没有藏在遮罩下面。毛玻璃是装饰性的磨砂马赛克，不是对原名做可辨认的轻微模糊。图片遮罩下方先绘制截图底色，因此透明 PNG 也不会露出名称。标题应用相同规则。

不导出头像、发言人标签或账号字段。额外别名和正文中的其他隐私文字仍需自行填写。全部处理在本地，不上传图片或字体，不保存名称规则，不引入 CDN。

## 性能与范围

仅打开面板时读取当前楼层，设置阶段不绘制截图。长文按时间片排版，屏幕外画布释放像素，导出逐页编码并可取消后续页。单次上限 120,000 字符、200 条匹配文本，每条不超过 500 字符。浏览器可能拦截多文件下载，可使用逐张保存。

导出纯文本及换行，不复制 Markdown 富文本、HTML 或正文图片。四套 CSS 排版变量为 --sb-paper、--sb-ink、--sb-body-size、--sb-line-height、--sb-pad；颜色可在面板中覆盖。英文可能在词中换行。

实现沿用常见 #chat .mes、.mes_text、.extraMesButtons 结构，通过 SillyTavern.getContext().name1 尝试获取 user 名称。不同版本或第三方主题可能需要适配。

按用户要求没有进行浏览器测试，未验证目标环境的视觉效果、兼容性或性能。
