# 楼层书摘 · SillyTavern 扩展

从消息的更多操作菜单（楼层菜单）打开书本图标「生成书摘」，把选中片段或整层正文保存成 PNG。四套排版、名称实心遮罩、长文自动分页，全部在浏览器本地处理。没有 CDN、网络请求、遥测或额外依赖，也不保存聊天原文和名称规则。

## 安装

将整个 `sillytavern-bookmark` 文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录，然后刷新页面，在扩展管理中启用「楼层书摘 · 私密摘录」。目录内部应直接包含 `manifest.json`、`index.js`、`style.css`。

这是本地扩展包，不是已经发布的 Git 仓库地址，不能把 ZIP 路径粘贴进“安装扩展”的仓库地址框。若需要从仓库安装，可把文件夹里的文件放到你自己的 Git 仓库根目录，再使用仓库地址安装。

## 使用

1. 想摘录片段时，先选中某层正文的文字，再打开该层更多操作菜单。
2. 点击书本图标「生成书摘」。没有选中片段时默认载入整层正文，也可以用面板按钮切换。
3. 确认 user 名称；自动获取不到时需手动填写，或主动取消 user 遮罩。额外打码文本每行一条，按字面精确匹配、区分大小写，长名称优先。别名需要单独填写。不支持正则表达式。
4. 选择温暖书页、极简留白、深色夜读或紧凑手记，选择字号。
5. 保存全部 PNG，或逐张保存。浏览器可能要求允许多个下载；手机浏览器也可能把图片交给自身的下载/保存界面。

编辑框显示未打码原文。预览和导出前先将匹配名称替换成实心方块，原名不会画在遮罩下面；标题也经过同样处理。图片不包含头像、发言人标签、账号字段或原文元数据。文件名固定为书摘页码，不包含名称。需要隐藏的正文信息仍须加入规则。

## 流畅性设计

- 启动时安装楼层菜单入口；后续只处理新增楼层/菜单，不读取所有聊天正文。
- 打开面板时才读取当前楼层。预览采用 140ms 防抖，修改隐私规则后立即清空旧预览，过期任务自动停止。
- 长文按约 7ms 时间片断行，给浏览器让出主线程；预览按页显示，屏幕外图片延迟绘制。
- PNG 每次只以双倍分辨率编码一页，完成后释放临时画布，支持取消剩余导出。
- 单次上限 120,000 字符、200 条打码文本。并非“绝不卡顿”保证：Canvas 编码、设备内存和浏览器下载机制仍影响速度。

## CSS 排版

四个模板在 `style.css` 中定义，渲染器读取 `--sb-paper`、`--sb-ink`、`--sb-accent`、`--sb-font`、`--sb-body-size`、`--sb-line-height`、`--sb-pad`，使预览与导出共用配色和字体。可修改这些变量制作个人风格；字号、行距和内边距变量为纯数字。

此版本导出正文纯文本，保留换行和可见文字；不复制 HTML、头像、正文图片或 Markdown 富文本样式。CSS 支持上述排版变量，不是任意网页 CSS 截图引擎。中文无空格自动换行，英文也可能在词中换行。

## 兼容性与验证状态

实现基于常见的 `#chat .mes`、`.mes_text`、`.extraMesButtons` DOM 结构，并尝试通过 `window.SillyTavern.getContext().name1` 获取 user 名称。不导入版本相关的内部模块。入口只插入楼层更多菜单，不会移到全局工具栏。若目标版本或第三方主题更改这些结构，可能需要调整选择器。

没有访问用户安装、聊天或浏览器；按用户要求，没有运行浏览器测试。也未联网核对目标版本或执行其他测试。此包是未经目标环境验证的实现，实际兼容性和性能尚未确认。
